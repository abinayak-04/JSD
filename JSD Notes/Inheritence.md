# Inheritence
- The mechanism deriving derive class from the old one is known as inheritance.
*Purpose*
- Reusability of code
 ## Types of inheritence
1) Single inheritance
    - only one base class and only one derive class is known as single inheritance.

2) Multiple inheritance
    - More than one base class and only one derive class (java does not support multiple inheritance so we can use interface concepts in next chapter)

3) Multilevel:
    - More than one level .

4) Hierarchical inheritance:
    - It is tree format : only one base class and more derive class.

5) Hybrid inheritance:
    - Combination of any two inheritance.

**Note**
- this - is inbuilt object of current class.
- super - object of base class.
