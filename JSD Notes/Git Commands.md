# Git 
- It is a distributed version control system used to track changes in code or files.



 **Install Git for your device,then in the command prompt check whether it is installed by using git in command.**

## Step 1 
 - Create repository (don't forget to click readme and license)
## Step 2 
-  Copy git repository link
## Step 3 
- Create new folder (d:/NmvmJSD)
## Step 4 
- Open command prompt and type: d: /nmvm> git clone Paste git link
## Step 5 
- cd git repository
## Step 6 
- In command prompt type: code . (to open files in visual studio code)
## Step 7 
- add files (create files)
## Step 8 
- git add .
## Step 9 
- git commit -m "Your Message" (on 1st time : verify email & user)
## Step 10 
- git push
## To delete a file
- Delete the file in vscode and then use these commands
  - git add . 
  -  git commit -m "your msg"
  -  git push
