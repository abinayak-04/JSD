# Constructor
- Constructor is a special member method.
- It is used to initialize object values.
## Types of constructor
 1. Default constructor or null constructor
 2. Argument or parametarized constructor
 3. Copy constructor
 4. Overloading constructor(polymorphisim)

 ### Rules of constructor
 - Classname and constructor name should be equal.
 - Constructor should not be private access.
 - Constructor has no return type(ie. Don't use void).
 - Constructor called at the time of the object creation.
