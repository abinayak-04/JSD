# ExpressJs
- It is a runtime or dynamic backend environment.
- It is used to get values from end user.
## Installation
- Create a new folder. 
    - Ex:- ExpressJS.
- Open terminal >cd ExpressJS
- Then enter >npm install express

## Two methods
1) get method (default)
- It will show all the form input values in URL.
2) post method
- It won't show all the form input values in URL.
- It provides high security (must know about body-parser)
